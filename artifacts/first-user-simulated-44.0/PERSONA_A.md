# Persona A — 일반 스마트폰 사용자

## 전제

- 앱/게임 숙련도: 보통
- 사용 태도: 화면의 큰 제목과 주요 CTA는 읽지만 긴 설명은 선택적으로 읽음
- 결과 관심: 중간 이상
- 이 기록은 실제 발화가 아닌 화면 근거 기반 시뮬레이션이다.

## 예상 행동

| 구간 | 예상 반응 |
|---|---|
| HOME 5초 | “쓸데없는 능력을 아주 정밀하게 재는 재미 검사”로 이해. 큰 emerald CTA를 바로 찾음. |
| INTRO | 5개 검사와 약 90초, 자연스럽게 하라는 안내는 이해. 보이는 poster에 7일 안내가 없어 오늘 한 번으로 끝난다고 예상. |
| DAY1 | 시간→중심→균형→통제→집중으로 조작이 바뀌어 반복감이 낮음. |
| Basic | 큰 점수·프로필·대표 자격을 보고 최종 결과라고 먼저 판단. 하단 `DAY 1 / 7`에 도달하면 뒤늦게 첫날 기준점임을 수정. |
| DAY2~4 | HOME의 DAY progress로 재방문 목적을 이해. DAY3 시각 유도와 DAY4 3등분은 전날과 구분됨. |
| DAY5 | `SURPRISE/변속 조건`을 보고 변화를 대비해 누르는 전략을 바꿀 가능성이 큼. |
| DAY6 | observe→clear→recall strip만으로 과제를 이해. 기억 재구성 결과가 인상적. |
| DAY7 | “6일 기록 중 하나를 마지막 확인”으로 정확히 이해. |
| Final | 완주 선언→보정→Change Map 흐름을 이해하고 공유 카드까지 탐색할 가능성이 높음. |

## 예상 지표

- HOME 이해 4/5, 7일 구조 2/5
- DAY1 재미 4/5, 피로 2/5
- Basic이 Final처럼 느껴짐: YES
- DAY2~6 반복감 2/5
- DAY5 Surprise 이해: YES, 단 condition priming 위험 있음
- DAY6 Memory 이해: YES
- DAY7 목적 5/5, Final 보상감 5/5
- Change Map: YES, Share 의향 4/5, Icon 적합성 4/5

## friction / reward / return

- Friction: 7일 구조를 너무 늦게 알게 됨.
- Reward: Final의 `DAY 7 / 7`, 선택 능력 보정, 변화 지도가 한 이야기로 연결됨.
- 다시 들어올 이유: HOME이 다음 DAY를 명시하기 때문에 DAY1 완료 후에는 충분함.
