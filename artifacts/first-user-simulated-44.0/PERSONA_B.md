# Persona B — 빠르게 넘기는 사용자

## 전제

- 앱/게임 숙련도: 높음
- 사용 태도: 큰 숫자와 버튼만 보고 설명/근거는 대부분 건너뜀
- 결과 관심: 즉각적인 결과에 집중
- 이 기록은 실제 발화가 아닌 화면 근거 기반 시뮬레이션이다.

## 예상 행동

| 구간 | 예상 반응 |
|---|---|
| HOME/INTRO | `약 90초`, `총 5개`, `측정 시작`만 기억. 7일 제품이라는 단서는 보이지 않아 1회성 테스트로 확신하기 쉬움. |
| DAY1 | CTA와 조작은 명확해 빠르게 완주. 개별 trial 결과를 읽지 않고 다음으로 이동. |
| Basic | 큰 종합 점수와 자격명만 보고 만족/이탈. 하단의 `DAY 1 / 7`까지 스크롤하지 않을 가능성이 가장 큼. |
| 재방문 HOME | DAY progress와 오늘의 추가 분석 CTA는 명확. 우연히 재방문하거나 알림이 없다면 DAY2 존재를 모른 채 종료할 수 있음. |
| DAY2~6 | 결과 상세는 건너뛰지만 daily hero/next teaser로 날짜 차이는 최소한 인지. DAY4는 숫자 카드가 많아 반복감이 상대적으로 높음. |
| DAY7/Final | DAY7의 3-fact strip은 빠르게 읽힘. Final 상단과 Change Map은 읽지만 evidence/details는 열지 않음. |

## 예상 지표

- HOME 이해 5/5, 7일 구조 1/5
- DAY1 재미 4/5, 피로 1/5
- Basic이 Final처럼 느껴짐: YES
- DAY2~6 반복감 3/5
- DAY5 Surprise/Day6 Memory: YES
- DAY7 목적 5/5, Final 보상감 4/5
- Change Map: YES, Share 의향 4/5, Icon 적합성 4/5

## friction / reward / return

- Friction: 첫 세션에서 7일 안내를 볼 수 없어 제품의 핵심 retention loop를 놓침.
- Reward: Change Map은 긴 설명 없이도 숫자 변화가 보여 이 persona에 특히 적합.
- 다시 들어올 이유: 재방문 HOME은 좋지만 첫날 종료 전에 next-day expectation이 hero 근처에 있어야 함.
