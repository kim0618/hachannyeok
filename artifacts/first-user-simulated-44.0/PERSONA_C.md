# Persona C — 설명을 꼼꼼히 읽는 사용자

## 전제

- 앱/게임 숙련도: 보통
- 사용 태도: 안내, 결과 근거, 경계 문구까지 읽음
- 결과 관심: 높음
- 이 기록은 실제 발화가 아닌 화면 근거 기반 시뮬레이션이다.

## 예상 행동

| 구간 | 예상 반응 |
|---|---|
| HOME/INTRO | 재미 목적·비진단·화면 전환 시 무효·5개 검사는 정확히 이해. 그러나 시각적으로 노출된 안내만으로는 7일 구조를 알아낼 수 없음. |
| DAY1 | 각 trial의 실제값과 오차 설명을 읽어 피로가 조금 늘지만 신뢰는 올라감. |
| Basic | `기본 분석 완료` 표현 때문에 first result임을 의심하지만, 큰 score/certification이 더 강해 하단 확인 전까지는 Final 여부가 모호함. |
| DAY2~6 | 비교 조건과 근거 해석을 잘 이해. DAY4 actual splits, DAY6 실제/선택 위치 연결을 특히 신뢰 근거로 평가. |
| DAY5 | 조건명을 미리 공개하는 이유를 의문시하고, 자신이 대비한 반응도 측정값인지 걱정할 수 있음. |
| DAY7 | 선택 대상과 선정 이유, DAY1~6 누적을 명확히 이해. |
| Final | Change Map→5개 능력→pattern→evidence→manual의 장 구조를 가장 잘 활용. `evidence` 혼용은 다듬어지지 않은 용어로 느낌. |

## 예상 지표

- HOME 이해 4/5, 7일 구조 2/5
- DAY1 재미 4/5, 피로 3/5
- Basic이 Final처럼 느껴짐: YES (확신은 낮음)
- DAY2~6 반복감 2/5
- DAY5 Surprise/Day6 Memory: YES
- DAY7 목적 5/5, Final 보상감 5/5
- Change Map: YES, Share 의향 4/5, Icon 적합성 5/5

## friction / reward / return

- Friction: 접근성 DOM에는 있는 핵심 7일 설명이 실제 poster에는 없다는 정보 불일치.
- Reward: raw evidence와 최종 변화의 연결성이 가장 큰 만족 요소.
- 다시 들어올 이유: 다음날 확인할 조건의 구체적 teaser가 충분함.
