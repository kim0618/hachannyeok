# Persona D — 게임/테스트 콘텐츠에 관심이 낮은 사용자

## 전제

- 앱/게임 숙련도: 낮음~보통
- 사용 태도: 보상이 즉시 보이지 않으면 이탈, 전문적인 영어 표현을 덜 선호
- 결과 관심: 낮음
- 이 기록은 실제 발화가 아닌 화면 근거 기반 시뮬레이션이다.

## 예상 행동

| 구간 | 예상 반응 |
|---|---|
| HOME | 고급스러운 계측기 화면과 90초 약속 때문에 한 번은 시작할 수 있음. 7일 참여 약속은 인지하지 못함. |
| DAY1 | 검사 자체는 짧지만 다섯 번의 ready/result 전환을 길게 느낄 수 있음. |
| Basic | 첫날에도 큰 점수와 자격 인증을 받아 충분히 끝났다고 느낌. DAY2까지 올 이유가 가장 약함. |
| DAY2~4 | 전날과 같은 능력 점수 화면으로 오해할 수 있으나 `오늘 새로 발견한 것`과 next teaser가 이를 완화. DAY4 숫자 밀도가 부담. |
| DAY5/6 | 움직임 변속과 위치 기억은 시각적으로 확실히 달라 흥미가 회복됨. |
| DAY7 | 최종이라는 목적은 이해하지만 Returning HOME의 `evidence`가 낯설 수 있음. |
| Final | 상단과 Change Map까지는 보지만 evidence와 manual 전체는 건너뛸 가능성이 큼. 공유는 낮음. |

## 예상 지표

- HOME 이해 4/5, 7일 구조 1/5
- DAY1 재미 3/5, 피로 2/5
- Basic이 Final처럼 느껴짐: YES
- DAY2~6 반복감 3/5
- DAY5 Surprise/Day6 Memory: YES
- DAY7 목적 4/5, Final 보상감 4/5
- Change Map: YES, Share 의향 2/5, Icon 적합성 4/5

## friction / reward / return

- Friction: 첫날 결과가 이미 충분히 완결되어 7일 완주 동기보다 종료 신호가 큼.
- Reward: DAY5/6의 동적인 과제와 Final 변화 지도가 긴 설명 없이 보상 제공.
- 다시 들어올 이유: 제품 밖 reminder가 없다면 낮음. 제품 안에서는 next teaser가 가장 유효함.
