# Persona E — 결과·공유에 관심이 높은 사용자

## 전제

- 앱/게임 숙련도: 보통~높음
- 사용 태도: 점수, 프로필, 인증, 공유 가능한 결과물을 적극 탐색
- 결과 관심: 매우 높음
- 이 기록은 실제 발화가 아닌 화면 근거 기반 시뮬레이션이다.

## 예상 행동

| 구간 | 예상 반응 |
|---|---|
| HOME | 프리미엄 리포트/자격 인증 결과를 기대하며 바로 시작. 7일 제품인지 알지 못해도 결과 기대가 진입을 견인. |
| DAY1/Basic | 큰 score, profile, certification을 좋아함. 공유 CTA도 사용 가능하지만 Basic과 Final의 위계 차이는 첫날에 약함. |
| DAY2~6 | 점수 변화와 condition comparison을 확인하므로 반복감이 낮음. next teaser가 완주 동기로 강하게 작동. |
| DAY7 | 선택 능력 하나를 보정한다는 희소성이 최종 기대감을 높임. |
| Final | completion motion, calibration summary, Change Map, 최종 대표 자격, share card 모두 보상으로 작동. 가장 긴 시간 탐색. |
| Share | 카드에서 overall/profile/5개 능력을 한 장에 확인하고 공유 CTA를 찾음. |

## 예상 지표

- HOME 이해 4/5, 7일 구조 3/5 (Basic까지 탐색 후 보정)
- DAY1 재미 5/5, 피로 1/5
- Basic이 Final처럼 느껴짐: NO에 가까움 (추가 결과를 적극 탐색)
- DAY2~6 반복감 2/5
- DAY5 Surprise/Day6 Memory: YES
- DAY7 목적 4/5, Final 보상감 5/5
- Change Map: YES, Share 의향 5/5, Icon 적합성 5/5

## friction / reward / return

- Friction: Basic share가 있어 첫날 결과만 공유하고 7일 Final의 차별점을 놓칠 수 있음.
- Reward: Final Share Card가 7일 완주를 가장 명확한 소유 가능한 결과물로 바꿈.
- 다시 들어올 이유: 점수 update, 대표 자격, 최종 카드 완성이 충분함.
