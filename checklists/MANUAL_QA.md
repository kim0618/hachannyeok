# 수동 QA 체크리스트

## 환경

- [ ] 실제 Android 기기
- [ ] 토스 샌드박스 또는 공식 테스트 환경
- [ ] 360px 수준 작은 화면
- [ ] 네트워크 느림/오프라인 상태

## 첫 진입

- [ ] 5초 안에 앱 목적 이해
- [ ] 메인 CTA가 스크롤 없이 보임
- [ ] 결과가 없는 내 결과 화면 정상

## 검사 공통

- [ ] 진행률 정확
- [ ] 빠른 연타가 중복 제출되지 않음
- [ ] 뒤로가기 처리
- [ ] 백그라운드 후 현재 시도 처리
- [ ] 화면 잠금 후 복귀
- [ ] 검사 완료 후 다음 화면 이동

## 시간 검사

- [ ] 3회 수행
- [ ] 숫자 표시/숨김 정상
- [ ] 백그라운드 시 시도 무효

## 중심/균형

- [ ] 가장자리 터치
- [ ] 스크롤과 포인터 충돌 없음
- [ ] 화면 크기가 달라도 결과 정상

## 통제

- [ ] 저성능 기기에서 프레임 드롭
- [ ] 두 번 탭 방지
- [ ] 애니메이션 종료 정리

## 집중

- [ ] 정답 위치가 편향되지 않음
- [ ] 오답 처리
- [ ] 너무 작은 터치 타깃 없음

## 결과

- [ ] 실제 원시 수치 표시
- [ ] 긴 결과 문구 잘림 없음
- [ ] 공유 취소/실패
- [ ] 재검사 정상

## 저장

- [ ] 앱 재실행 후 결과 유지
- [ ] 깨진 저장값 복구
- [ ] 초기화 확인 후 삭제
