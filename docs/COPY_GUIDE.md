# 카피 가이드

## 톤

- 보고서처럼 건조하다.
- 짧고 단정하다.
- 억지 밈을 쓰지 않는다.
- 사용자를 모욕하지 않는다.
- 실제 측정값과 연결한다.

## 좋은 예

- 조금 늦지만 꽤 일정합니다.
- 중심보다 오른쪽 위를 선호하는 경향이 있습니다.
- 속도가 빨라질수록 손가락이 먼저 판단합니다.
- 활용처는 아직 확인되지 않았습니다.
- 친구 피자 크기 감시에 적합합니다.
- 추가 훈련은 권장하지 않습니다.

## 나쁜 예

- 와ㅋㅋ 시간감각 레전드
- 당신은 감각이 없습니다.
- 전국 상위 1%입니다. (실제 데이터가 없으므로 금지)
- 10만 명이 참여했습니다. (실제 데이터가 없으므로 금지)

## 낮은 점수 표현

낮은 점수도 결함이 아니라 관심 부족이나 성향으로 표현한다.

- 감각이 없다 → 정확한 중심에 큰 관심이 없는 편입니다.
- 너무 느리다 → 충분히 확인한 뒤 반응하는 편입니다.
- 너무 빠르다 → 상황보다 손가락이 먼저 결론을 냅니다.
