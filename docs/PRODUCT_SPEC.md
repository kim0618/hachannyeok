# 제품 명세 — 하찮력

## 목적

일상에 거의 쓸모없는 감각을 실제 행동으로 측정하고, 이를 필요 이상으로 진지하게 분석해 재미있는 결과를 제공한다.

## 핵심 가치

- 질문형 테스트가 아닌 행동 측정형 검사
- 실제 수치 기반 결과
- 건조한 유머와 가상 자격 체계
- 가입·서버 없이 바로 끝나는 완결형 경험

## 핵심 사용자 흐름

홈 → 검사 안내 → 5개 순차 검사 → 종합 결과 → 상세 분석 → 공유 또는 재검사

## 5개 검사

1. 시간 감각: 3초를 감으로 맞히기
2. 중심 인지: 도형 중심을 터치하기
3. 균형 분배: 영역을 2등분·3등분하기
4. 손가락 통제: 움직이는 바를 목표 지점에서 멈추기
5. 시각 집중: 유사 항목 중 다른 항목 찾기

## 결과 구성

- 종합 하찮력 점수
- 능력별 점수 5개
- 정확도·일관성·속도·적응성 특성
- 종합 유형
- 대표 자격 및 보조 자격
- 실제 측정값
- 활용 가능 분야와 비권장 업무

## MVP 필수

- 홈
- 검사 안내
- 5개 검사
- 중간 결과 카드
- 종합 결과
- 상세 분석
- 로컬 저장
- 재검사
- 결과 공유
- 기록 초기화

## 출시 후가 아니라도 선택 구현 가능

- 오늘의 검사
- 이전 결과 대비 변화
- 주간 요약

## 제외 범위

서버, DB, 로그인, 온라인 랭킹, 친구 관계, 실시간 비교, 결제, 광고, 게시판, AI 호출.
