# 제품 명세 — 하찮력

## 제품 정의

`하찮력`은 Apps in Toss용 비게임 행동 기반 검사 앱이다. 사용자가 실제 행동 검사를 수행하면 일상에 거의 쓸모없는 능력을 실제 수치로 분석하고, 서로 다른 날짜에 짧은 추가 검사를 이어가며 7번째 분석일에 개인 하찮력 사용설명서를 완성한다.

## 핵심 가치

- 질문형 테스트가 아닌 행동 측정형 검사
- 실제 원시 측정값에 근거한 결정적 결과
- 첫날만으로도 완결된 기본 분석
- 추가 방문마다 새롭게 확인되는 자기 발견
- 건조한 유머와 가상 자격 체계
- 가입·서버 없이 현재 기기에서 끝나는 경험

재방문 보상은 코인·포인트·출석 보상이 아니라 “오늘 검사하면 내 분석 결과가 어떻게 달라질까?”라는 질문에 대한 새로운 정보다.

## 7일의 의미

- DAY는 달력상 연속 출석일이 아니라 사용자가 검사를 완료한 **분석일 순서**다.
- DAY 1 이후 각 추가 분석은 서로 다른 로컬 날짜에 하루 한 번만 완료할 수 있다.
- 방문을 놓쳐도 진행 상태나 결과를 잃지 않으며 다음 방문에서 이어서 진행한다.
- 같은 날짜에 여러 분석일을 몰아서 완료할 수 없다.
- 연속 방문, 마감 압박, 결석 손실을 보상이나 카피에 사용하지 않는다.

## DAY 1 — 종합검사와 기본 분석

첫 방문 사용자는 약 90초 동안 다음 5개 검사를 순서대로 수행한다.

1. 시간 감각
2. 중심 인지
3. 균형 분배
4. 손가락 통제
5. 시각 집중

각 검사는 가능하면 2~3회 측정해 우연성을 줄이고 원시 측정값을 보존한다.

DAY 1 결과는 다음을 모두 포함한다.

- 기본 하찮력 종합점수
- 5개 능력치
- 기본 유형
- 대표 자격 2~3개
- 실제 측정값
- 강점과 보완 영역
- 기본 사용설명서
- DAY 1 공유 카드
- 분석 진행 상태

DAY 1 결과는 그 자체로 완결되어야 한다. 추가 분석을 하지 않아도 빈약하거나 미완성된 결과처럼 보이면 안 된다. 진행 상태는 `기본 분석 완료`처럼 표현하고, 추가 분석으로 더 정교해질 수 있음을 안내한다. `65%` 같은 수치를 노출한다면 사용자 테스트로 조정 가능한 상수로 취급한다.

## DAY 2~6 — 오늘의 추가 분석

각 분석일에는 10~20초짜리 추가 검사 하나를 제공한다.

| 분석일 | 추가 검사 예시 | 새로 확인하는 근거 |
| --- | --- | --- |
| DAY 2 | 5초 시간 감각 | 시간 편향 |
| DAY 3 | 장식이 있는 도형 중심 찾기 | 시각 편향 |
| DAY 4 | 3등분 검사 | 다중 분배 성향 |
| DAY 5 | 속도가 변하는 정지 검사 | 압박 상황 통제력 |
| DAY 6 | 순간 위치 기억 | 집중·기억 하위 특성 |

각 추가 검사 후 다음 중 최소 3개가 실제 측정 근거에 따라 변해야 한다.

- 새로운 행동 특성 공개
- 관련 능력치 업데이트
- 자격 변경 또는 승급
- 유형 설명 보정
- 분석 진행 상태 증가
- 이전 결과 대비 변화 표시

추가 검사 하나가 DAY 1 전체 결과를 덮어쓰거나 종합 유형을 임의로 뒤집어서는 안 된다.

## DAY 7 — 최종 분석

DAY 7에는 짧은 종합 보정 검사 또는 최종 분석을 제공한다. 완료 후 다음을 제공한다.

- 최종 하찮력 유형
- 최종 5개 능력치
- 최종 사용설명서
- 심화·특급 자격
- 7일 변화 리포트
- 강점과 약점
- 취급 주의사항
- 활용 가능 분야
- 가장 안정적인 능력
- 가장 흔들리는 능력
- 가장 많이 개선된 능력
- 최종 공유 카드

DAY 7 결과는 DAY 1 결과와 정보 구조와 시각적 위계에서 명확히 구분한다.

## 사용자 상태 머신

| 상태 | 조건 | 홈의 핵심 정보 | Primary CTA |
| --- | --- | --- | --- |
| STATE A | 첫 방문 또는 DAY 1 종합검사 미완료 | 제품 설명, 검사 5개, 예상 시간 | `정밀검사 시작` 또는 `검사 이어하기` |
| STATE B | DAY 1 완료, 같은 날짜에 다음 분석 불가 | 기본 결과, 대표 자격, 다음 분석 안내 | `기본 분석서 보기` |
| STATE C | DAY 2~6 추가 분석 가능 | 진행 상태, 오늘 확인할 항목, 최근 특성 | `오늘의 추가 분석` |
| STATE D | 오늘 추가 분석 완료 | 새 특성, 능력 변화, 다음 분석 안내 | `업데이트된 분석서 보기` |
| STATE E | DAY 7 최종 분석 가능 | 누적 근거 요약, 최종 분석 안내 | `최종 분석 시작` |
| STATE F | DAY 7 완료 | 최종 유형, 최종 자격, 변화 요약 | `최종 사용설명서 보기` |

검사 도중 종료한 STATE A는 저장 가능한 마지막 안전 지점부터 재개하거나 현재 검사부터 다시 시작한다. 부분 측정값을 유효 결과로 계산하지 않는다.

## 기존 사용자 홈

DAY 1 이후 홈에는 최소 다음을 제공한다.

- 현재 분석 진행 상태
- 오늘 추가 분석 가능 여부
- 최근 새롭게 발견된 특성
- 현재 대표 자격
- 최근 능력 변화
- 내 분석서 보기

## 공유와 유입

공유 결과에는 유형명만 넣지 않고 실제 측정값을 포함한다.

- 대표 자격
- 실제 측정 수치 최소 2개
- 앱명
- DAY 1: `너도 90초 동안 측정해 보기`
- DAY 7: 최종 변화와 심화 결과를 포함한 별도 CTA

DAY 1 공유는 기본 결과의 완결성을, DAY 7 공유는 누적 근거와 변화의 깊이를 강조한다. 실제 전국 수치, 백분위, 이용자 수는 표시하지 않는다.

## MVP 필수

- 상태별 홈과 검사 안내
- DAY 1 종합검사 5개와 중간 결과
- DAY 1 기본 분석·상세 분석·공유
- DAY 2~6 추가 분석과 변화 표시
- DAY 7 최종 분석·최종 리포트·공유
- 버전이 있는 기기 로컬 저장
- 중복 실행 방지, 재개·재시도, 기록 초기화

## 제외 범위

서버, 외부 DB, 로그인, 온라인 랭킹, 친구 관계, 친구 전적, 승패, 실시간 비교, 결제, 광고, 게시판, AI 호출, 랜덤 유형, 가짜 백분위, 코인, 포인트, 캐릭터 성장, 연속 출석 보상.
