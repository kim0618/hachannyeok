# QA 명세

## 자동 테스트

- 점수 계산 경계값
- 빈 입력과 잘못된 입력
- 유형 판정
- 자격 등급
- 날짜 기반 오늘의 검사 선택
- 로컬 저장 직렬화·역직렬화
- 저장 버전 마이그레이션

## 수동 테스트

- 360×800 작은 화면
- 큰 글자 설정 또는 긴 한글 결과
- 매우 빠른 연속 탭
- 검사 중 앱 백그라운드 이동
- 검사 중 뒤로가기
- 화면 잠금 후 복귀
- 공유 취소
- 저장소 오류
- 기존 기록이 없는 첫 사용자
- 기록 초기화
- 재검사

## 출품 전 목표

- 첫 화면 목적 이해: 5초 이내
- 첫 검사 시작: 10초 이내
- 종합검사 완료: 90~120초
- 주요 CTA 잘림 없음
- 로딩 무한 상태 없음
- 사용자에게 가짜 통계 표시 없음
