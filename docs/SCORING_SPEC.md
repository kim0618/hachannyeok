# 점수 및 결과 엔진 명세

## 공통 원칙

- 모든 능력 점수는 0~100 범위다.
- 실제 백분위나 전국 순위처럼 표현하지 않는다.
- 실제 원시 측정값을 별도로 보존한다.
- 같은 유효 입력은 항상 같은 결과를 만든다.
- 랜덤 유형과 근거 없는 자격 변경을 금지한다.
- 한 번의 최고 기록만으로 점수를 결정하지 않는다.
- 정확도와 일관성을 기본 축으로 사용한다.
- 점수 계수와 분석 진행 표시값은 사용성·측정 테스트 후 조정 가능한 상수로 분리한다.
- 이번 단계에서는 정밀 계수나 복잡한 수학 공식을 고정하지 않는다.

## 공통 타입

```ts
export type AbilityScores = {
  time: number;
  center: number;
  balance: number;
  control: number;
  focus: number;
};

export type MetaTraits = {
  accuracy: number;
  consistency: number;
  speed: number;
  adaptability: number;
  tendencies: BiasTendency[];
};
```

`BiasTendency`는 early/late, 좌우·상하 편향처럼 실제 측정에서 반복 관찰된 방향성과 근거 수를 가진다.

## DAY 1 baseline

- 5개 검사의 유효한 2~3회 측정으로 baseline을 만든다.
- DAY 1 결과는 기본 종합점수, 5개 능력치, 메타 특성, 기본 유형, 대표 자격 2~3개를 완결된 형태로 제공한다.
- baseline 원시 측정값과 baseline 점수는 이후에도 보존한다.
- 추가 분석은 baseline 전체를 덮어쓰지 않는다.

초기 종합점수 구조는 다음과 같이 동일 가중 평균을 기본값으로 둘 수 있다.

```text
(time + center + balance + control + focus) / 5
```

실제 테스트 후 조정할 수 있지만 특정 능력에 과도한 가중치를 주지 않는다.

## 능력별 DAY 1 입력과 산출

### 시간 감각

- 입력: 목표 시간, 유효한 실제 시간 2~3회
- 산출: signed error, 평균 절대 오차, 변동성, early/late/neutral 편향
- 초기 구조: 정확도와 일관성을 함께 반영

### 중심 인지

- 입력: 정규화된 영역 크기, 실제 중심, 사용자 터치 좌표
- 산출: 대각선 대비 거리 오차율, x/y 편향, 회차 일관성

### 균형 분배

- 입력: 사용자 분할 위치, 목표 비율
- 산출: 비율 절대 오차, 방향 편향, 2등분·3등분 성능 차이

### 손가락 통제

- 입력: 목표 위치, 정지 위치, 속도 단계
- 산출: 정규화 위치 오차, 속도별 정확도, early/late 경향, 회차 일관성

### 시각 집중

- 입력: 정답 여부, 반응 시간, 난도
- 산출: 정확도, 정답 시 반응 시간, 난도 변화에 대한 적응

## DAY 2~6 증분 업데이트

- 추가 검사는 연결된 능력과 특성만 업데이트한다.
- baseline과 기존 누적 근거를 모두 입력으로 사용한다.
- 새 측정 하나가 기존 여러 측정을 압도하지 않도록 근거 수와 신뢰도를 반영한다.
- `previousAbilityScores`는 업데이트 직전 값을, `currentAbilityScores`는 업데이트 후 값을 나타낸다.
- 실제 변화가 표시 최소 단위보다 작으면 `변화 없음` 또는 `더 안정적으로 확인됨`으로 표현할 수 있다.
- 오답·무효 시도·극단값 처리 원칙을 능력별 순수 함수에 명시한다.
- 추가 검사 하나로 무관한 능력치를 바꾸지 않는다.

정확한 가중치, 감쇠율, 일일 최대 변화량은 3단계 이후 테스트 가능한 상수로 정한다.

## DAY 7 최종 분석

- baseline과 DAY 2~6의 모든 유효 측정 근거를 사용한다.
- 최종 능력치, 메타 특성, 유형, 자격, 변화 리포트를 결정적으로 생성한다.
- 가장 안정적인 능력: 여러 측정일에서 변동성이 가장 낮은 유효 능력
- 가장 흔들리는 능력: 여러 측정일에서 변동성이 가장 높은 유효 능력
- 가장 많이 개선된 능력: baseline 대비 최종 점수의 양의 변화가 가장 큰 유효 능력
- 동률·근거 부족 규칙은 명시적인 우선순위 또는 `판단 근거 부족`으로 처리한다.

## 유형 판정 안정성

유형은 다음 근거 조합으로 결정한다.

- 최고·최저 능력
- 가장 강한 메타 특성
- 반복 관찰된 편향
- 근거 수와 신뢰도

DAY 2~6에는 설명과 보조 특성을 점진적으로 보정한다. 유형 변경은 새 근거가 기존 판정 경계를 충분히 넘을 때만 허용하며, 하루 검사 하나로 임의 반전되지 않게 한다. DAY 7에서 최종 유형을 확정한다.

## 자격 판정

- 자격은 실제 능력·특성 조건에 연결한다.
- DAY 1에는 대표 자격 2~3개를 제공한다.
- DAY 2~6에는 새 근거가 조건을 충족할 때만 변경·승급한다.
- DAY 7에는 누적 근거가 필요한 심화·특급 자격을 판정한다.
- 자격명은 재미를 위한 가상이지만 발급 근거는 실제 측정값이어야 한다.

## 분석 진행 상태와 신뢰도

- 진행 상태는 완료한 유효 분석 단계와 공개된 근거를 나타낸다.
- 진행 상태가 점수의 높고 낮음이나 실제 통계적 신뢰구간을 뜻하지 않게 한다.
- 숫자 비율을 표시한다면 사용자 테스트로 조정 가능한 표시 상수로 분리한다.
- 여러 날짜의 근거가 쌓일수록 관련 해석의 신뢰도는 증가하지만 과학적 진단처럼 표현하지 않는다.

## 필수 테스트

- 0~100 범위, NaN, Infinity, 빈 입력, 무효 시도
- 같은 입력의 결정성
- baseline 보존
- 관련 능력만 증분 업데이트되는지
- 중복 daily record의 이중 반영 방지
- 하루 측정 하나가 전체 유형을 부당하게 뒤집지 않는지
- 동률과 근거 부족 처리
- DAY 1 대비 DAY 7 변화 계산
- 유형과 자격 규칙의 충돌·도달 불가능 상태
