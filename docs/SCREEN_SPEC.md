# 화면 명세

## 공통 원칙

- 모바일 세로 화면과 360×800 뷰포트를 우선한다.
- 한 화면에는 핵심 행동 하나만 제공한다.
- 사용자가 현재 분석일, 오늘 가능 여부, 다음 행동을 즉시 이해해야 한다.
- 연속 출석이나 놓친 날의 손실을 암시하지 않는다.

## 1. 홈 — STATE A

첫 방문 또는 DAY 1 미완료 상태다.

- 앱명: 하찮력
- 헤드라인: `쓸데없는 능력을 정밀하게 측정합니다.`
- 메타: `총 5개 검사 · 약 90초`
- 검사 목록
- Primary CTA: `정밀검사 시작`
- 진행 중 안전한 재개점이 있으면 CTA: `검사 이어하기`
- 결과가 없을 때의 `내 분석서 보기` 처리
- 안내: 결과는 현재 기기에 저장됨

## 2. DAY 1 검사 안내

- 5개 검사 목록과 예상 시간
- 각 검사가 2~3회 측정될 수 있다는 안내
- 실제 행동값으로 분석한다는 설명
- 로컬 저장과 중단 시 재시도 안내
- CTA: `검사 시작하기`

## 3. 검사 공통 화면

- 상단 진행률: `검사 n / 5` 또는 추가 분석 단계
- 검사명과 두 줄 이하 안내
- 넓은 인터랙션 영역
- 시도 진행 표시
- 검사 중 다른 메뉴 숨김
- 중복 입력 방지
- 백그라운드 전환이나 중단으로 무효가 된 시도의 재시도 안내

## 4. DAY 1 중간 결과

- 핵심 원시 수치 한 줄
- 짧은 측정 기반 해석
- 다음 검사 예고
- CTA: `다음으로`

## 5. DAY 1 기본 분석 결과

DAY 1만 완료해도 완결된 결과로 보여야 한다.

정보 우선순위:

1. 기본 하찮력 종합점수
2. 기본 유형
3. 대표 자격 2~3개
4. 실제 측정값
5. 강점과 보완 영역
6. 기본 사용설명서
7. 분석 상태: `기본 분석 완료`
8. 상세 분석
9. 공유·재검사

추가 분석은 결과를 잠그기 위한 조건처럼 보이지 않게 `더 정교하게 확인할 수 있음`으로 안내한다.

## 6. 기존 사용자 홈 — STATE B~F

공통 요소:

- 현재 분석 상태
- 오늘 추가 분석 가능 여부
- 최근 새롭게 발견된 특성
- 현재 대표 자격
- 최근 변화
- `내 분석서 보기`

상태별 CTA:

- STATE B: `기본 분석서 보기`, 다음 분석 가능 시점 안내
- STATE C: `오늘의 추가 분석`
- STATE D: `업데이트된 분석서 보기`
- STATE E: `최종 분석 시작`
- STATE F: `최종 사용설명서 보기`

## 7. 오늘의 추가 분석 — DAY 2~6

시작 화면:

- 현재 분석일
- 오늘 확인할 능력 또는 특성
- 예상 시간 10~20초
- 완료 후 무엇이 새로 확인되는지에 대한 짧은 안내
- CTA: `추가 분석 시작`

완료 화면에는 최소 3개 이상의 실제 변화가 보이도록 구성한다.

- 새 행동 특성
- 관련 능력치 전후 값
- 자격 변경 또는 승급
- 유형 설명 보정
- 분석 진행 상태
- 이전 결과 대비 변화

## 8. 오늘 분석 완료 — STATE D

- `오늘 분석 완료`
- 새로 확인된 특성
- 업데이트된 능력 또는 자격
- 다음 분석은 다른 로컬 날짜에 가능하다는 중립적 안내
- CTA: `업데이트된 분석서 보기`

연속 출석, 카운트다운, 손실 회피 문구를 표시하지 않는다.

## 9. DAY 7 최종 분석 — STATE E

- 지금까지 쌓인 측정 근거 요약
- 짧은 종합 보정 검사 또는 최종 분석 안내
- 예상 시간
- CTA: `최종 분석 시작`

## 10. 최종 사용설명서 — STATE F

DAY 1과 명확히 다른 최종 결과 위계를 사용한다.

1. 최종 분석 완료 표시
2. 최종 하찮력 유형
3. 최종 5개 능력치
4. 심화·특급 자격
5. 7일 변화 리포트
6. 가장 안정적·흔들림·개선된 능력
7. 강점·약점·취급 주의사항
8. 활용 가능 분야
9. 실제 누적 측정 근거
10. 최종 공유 카드

## 11. 내 분석서

- 현재 유형과 능력치
- 분석 진행 상태
- 공개된 행동 특성
- 자격 목록
- 실제 측정값
- 이전 결과 대비 변화
- 완료된 분석일 기록
- 기록 초기화
- 현재 기기 저장 및 삭제 시 복구 불가 안내

## 12. 공유

DAY 1 공유 카드:

- 기본 유형과 대표 자격
- 실제 측정값 최소 2개
- `너도 90초 동안 측정해 보기`

DAY 7 공유 카드:

- 최종 유형과 심화 자격
- 실제 누적 측정값과 대표 변화
- DAY 1보다 높은 정보 밀도와 시각적 완성도

공유 취소·실패 시 현재 화면과 결과를 유지한다.

## 13. 오류와 빈 상태

- 손상된 저장 데이터: 안전한 기본값 복구 또는 초기화 안내
- 저장 실패: 메모리에서 검사를 계속하고 저장 실패 안내
- 결과 없는 직접 진입: 홈 또는 종합검사 안내
- 오늘 검사 중복 실행: 완료 결과 표시, 재계산 금지
- 날짜 변경 중 화면 유지: 제출 시점에 날짜를 다시 확인하고 안전하게 안내
- 검사 중 앱 종료: 불완전한 시도 폐기, 마지막 안전 지점부터 재개
