# 화면 명세

## 1. 홈

### 목적
앱의 정체성을 즉시 전달하고 종합검사를 시작하게 한다.

### 필수 요소
- 앱명: 하찮력
- 헤드라인: 쓸데없는 능력을 정밀하게 측정합니다.
- 메타: 총 5개 검사 · 약 90초
- Primary CTA: 정밀검사 시작
- Secondary: 내 결과 보기
- 선택: 오늘의 검사
- 작은 안내: 결과는 취업과 자산 형성에 도움이 되지 않습니다.

## 2. 검사 안내

- 총 5개 항목 목록
- 예상 시간
- 로컬 저장 안내
- CTA: 검사 시작하기

## 3. 검사 공통 화면

- 상단 진행률 `검사 n / 5`
- 검사명
- 두 줄 이하 안내
- 넓은 인터랙션 영역
- 시도 진행 표시
- 검사 중 다른 메뉴 숨김

## 4. 미드 결과

- 핵심 원시 수치 한 줄
- 짧은 해석 한 줄
- 다음 검사 예고
- CTA: 다음으로

## 5. 종합 결과

정보 우선순위:

1. 종합점수
2. 종합 유형
3. 대표 자격
4. 강점과 보완 영역
5. 상세 분석 버튼
6. 공유·재검사

## 6. 상세 분석

- 능력별 점수
- 행동 특성
- 실제 측정값
- 자격 목록
- 활용 가능 분야
- 비권장 업무

## 7. 내 결과

- 현재 결과
- 이전 결과 대비 변화
- 최근 검사 기록
- 기록 초기화
- 로컬 저장 안내

## 8. 오늘의 검사

- 날짜 기반으로 하나의 짧은 검사 선택
- 10~20초 이내
- 완료 결과를 기존 분석에 선택적으로 반영
