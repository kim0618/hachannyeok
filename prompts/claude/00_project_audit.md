# 00 — 프로젝트 감사 및 실행 계획

프로젝트 루트의 `CLAUDE.md`, `docs/*`, `templates/PROJECT_VARIABLES.md`를 모두 읽어.

Apps in Toss MCP를 사용해 다음을 확인해.

- 현재 권장 WebView 프로젝트 구조
- SDK와 TDS 버전 및 프로젝트 설정
- 비게임 미니앱 필수 출시 기준
- 로컬 저장과 공유 기능의 공식 지원 방식

그다음 현재 저장소를 분석해서 다음을 보고해.

1. 현재 프로젝트 구조와 생성 상태
2. package.json 실제 스크립트
3. Apps in Toss 설정 파일 상태
4. 누락된 필수 설정
5. 구현 단계를 12개 이하로 나눈 계획
6. 각 단계의 수정 예상 파일과 검증 방법

아직 코드를 수정하지 마. 추측하지 말고 공식 문서와 현재 저장소에 근거해 계획만 작성해.
