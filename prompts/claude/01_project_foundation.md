# 01 — 프로젝트 기반 구축

감사 결과를 바탕으로 기반만 구현해.

범위:

- granite 설정의 앱명, 표시명, 브랜드 색상 정리
- 앱 기본 라우팅 또는 화면 전환 구조
- 디자인 토큰
- 전역 오류 경계
- 검사 세션 타입과 빈 상태 구조
- 홈, 검사 안내, 빈 검사 화면, 빈 결과 화면 연결
- 테스트 환경이 없다면 최소 단위 테스트 환경 구성
- typecheck/lint/test/build 스크립트 정리

제외:

- 실제 검사 로직
- 점수 계산
- 로컬 기록 저장
- 공유 구현
- 오늘의 검사

완료 시 홈에서 검사 안내를 거쳐 빈 검사 화면까지 이동할 수 있어야 한다.
