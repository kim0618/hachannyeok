# 02 — 홈과 검사 안내 UI

`docs/SCREEN_SPEC.md`와 `docs/DESIGN_SYSTEM.md`에 맞춰 홈과 검사 안내 화면을 완성해.

홈 필수:

- 하찮력 브랜드명
- ‘쓸데없는 능력을 정밀하게 측정합니다.’
- ‘총 5개 검사 · 약 90초’
- Primary CTA ‘정밀검사 시작’
- 결과가 없는 상태의 ‘내 결과 보기’ 처리
- 하단 작은 유머 문구

안내 필수:

- 5개 검사 목록
- 예상 시간
- 로컬 저장 안내
- 검사 시작 CTA

요구사항:

- TDS 우선
- 360px 폭에서 CTA가 첫 화면 내에 보여야 함
- 한 화면 메시지 2줄 원칙
- 접근 가능한 버튼 이름
- 불필요한 탭 구조 추가 금지
