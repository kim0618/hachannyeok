# 03 — 시간 감각 검사

시간 감각 검사를 3회 측정 방식으로 구현해.

동작:

1. 사용자가 준비 버튼을 누른다.
2. 짧은 준비 후 측정이 시작된다.
3. 숫자는 잠시 표시된 뒤 사라진다.
4. 사용자가 정확히 3초라고 느낄 때 탭한다.
5. 총 3회 수행한다.

기술 요구:

- `performance.now()` 사용
- 원시 trial ms 보존
- signed error, 평균 절대 오차, 변동성 계산
- early/late/neutral 편향 산출
- 정확도 70%, 일관성 30% 구조의 순수 점수 함수
- `visibilitychange` 또는 공식 권장 방식으로 백그라운드 이동 시 현재 시도 무효
- 빠른 중복 탭 방지
- 3회 완료 후 미드 결과 카드
- 관련 단위 테스트

점수 계수는 임시 상수로 분리하고 사용성 테스트 전 값임을 주석으로 명시해.
