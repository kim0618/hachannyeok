# 08 — 종합 점수·유형·자격 엔진

5개 검사 결과를 조합하는 결과 엔진을 구현해.

필수 산출:

- AbilityScores 5개
- MetaTraits: accuracy, consistency, speed, adaptability
- 종합점수
- 최고 능력과 최저 능력
- 종합 유형
- 대표 자격 1개
- 보조 자격 목록
- 사용 설명서
- 활용 가능 분야와 비권장 업무

요구사항:

- 결과 로직은 UI와 분리된 순수 함수
- 유형 데이터와 자격 데이터는 `content` 파일로 분리
- 최소 24개 이상의 조합형 유형이 가능하도록 규칙 기반 설계
- 검사 원시 수치를 결과에 연결
- 낮은 결과도 모욕 없이 표현
- 결정적 결과: 같은 입력은 항상 같은 결과
- 광범위한 단위 테스트
