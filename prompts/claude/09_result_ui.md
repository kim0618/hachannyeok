# 09 — 결과 메인·상세 분석 UI

결과 엔진을 기반으로 결과 화면을 구현해.

메인 화면 정보 순서:

1. 종합 하찮력 점수
2. 종합 유형
3. 대표 자격
4. 강점과 보완 영역
5. 상세 분석 CTA
6. 공유와 재검사

상세 화면:

- 능력별 점수 막대
- 행동 특성
- 실제 측정값
- 발급 자격 목록
- 사용 설명서
- 활용 가능 분야 / 비권장 업무

요구사항:

- 360px 폭에서 잘리지 않음
- 대표 자격이 가장 기억에 남도록 시각 강조
- 레이더 차트보다 읽기 쉬운 막대 우선
- 긴 한글 유형명 대응
- 결과가 없는 직접 진입 처리
