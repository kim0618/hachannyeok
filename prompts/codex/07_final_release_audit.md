# Codex 07 — 최종 출시 감사

`AGENTS.md`, 모든 docs, checklists를 읽고 전체 저장소를 감사해.

1차는 수정 없이 critical / major / minor 목록을 작성해.

반드시 확인:

- 앱인토스 공식 비게임 기준
- SDK API 추측 또는 구식 사용
- 빌드 산출물
- 타입·린트·테스트·빌드
- 5개 검사 완주 흐름
- 백그라운드·뒤로가기·중복 탭
- 로컬 저장과 초기화
- 접근성·작은 화면
- 가짜 순위·온라인 기능 흔적
- 불필요한 패키지와 개발 코드

승인 후 critical과 major만 수정하고 전체 검증을 다시 실행해.
