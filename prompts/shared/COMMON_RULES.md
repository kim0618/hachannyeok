# 모든 프롬프트 끝에 붙이는 공통 규칙

1. `CLAUDE.md` 또는 `AGENTS.md`와 관련 `docs/` 문서를 먼저 읽어.
2. 앱인토스 관련 기능은 공식 MCP 또는 docs-search로 확인해.
3. SDK API를 추측해서 만들지 마.
4. 요청 범위 밖 기능과 파일은 수정하지 마.
5. 제품을 게임, 랭킹, 서버형 앱으로 확장하지 마.
6. 새 패키지 설치 전 필요성과 대안을 설명해.
7. 구현 후 실제 존재하는 typecheck, lint, test, build 명령을 실행해.
8. 실패한 검사를 숨기지 말고 정확히 보고해.
9. 변경 파일, 핵심 설계, 테스트 결과, 남은 위험을 요약해.
10. `templates/PROGRESS.md`를 갱신해.
