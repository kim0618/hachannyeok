# 단계 종료 공통 프롬프트

이번 단계 변경사항만 대상으로 마무리 검증해.

1. git diff를 검토해 요청 범위를 벗어난 변경이 없는지 확인해.
2. 실제 package.json 스크립트를 확인해 typecheck, lint, test, build를 실행해.
3. 실패하면 원인을 수정하되, 제품 명세나 점수 공식을 임의로 바꾸지 마.
4. 변경 파일 목록과 각 파일의 역할을 요약해.
5. 알려진 제약과 다음 단계에서 처리할 사항을 기록해.
6. `templates/PROGRESS.md`를 갱신해.
7. 내가 확인하기 전에는 다음 단계 구현을 시작하지 마.
